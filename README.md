# scale-extrapolation

Can a generative model whose weights are shared across scales (RG fixed-point as
architecture) be trained on cheap small fields and generate at 4–16× the resolution with
certified statistics — and what scale-dependent "running couplings" must it learn for the
non-Gaussian structure to survive extrapolation?

Current phase: **stage-0** (no model — measure the scale-drift of conditional wavelet
statistics directly on GRF / lognormal / N-body fields). See `PLAN.md`.
