# Archived campaign documents

These are the operational documents of the completed experimental campaign
(stage 0 → phase 3b): plans, night orders, night reports, arm specs, and the
superseded results/method files. They are kept because the `log/` rulings
reference them and because they are the record of how the work was run.

**They are history, not instructions.** Nothing here should be treated as a
live plan. The live documents are at the repo root:

- `HANDOFF.md` — binding state, operating rules, task queue
- `PROMPTS.md` — paste-ready prompt per task
- `NUMBERS.md` — canonical figures (generated from artifacts)
- `PROJECT-EXPLAINER.md` — the science in prose
- `BRIEF-foundations.md` — ranked research directions
- `SCOPE-FORK-MEMO.md` — the open framing decision
- `PLAN-phase3.md` — the last campaign plan (context for the log rulings)

Older `log/` entries may reference these files by their former root paths
(e.g. `NIGHT-ORDERS-2.md`); they now live here.
